Actividad: Algoritmo - Ordenar tres números

Inicio

    Colocar tres tarjetas con números sobre una mesa, una al lado de la otra.
    Identificar sus posiciones como primera, segunda y tercera.
    Comparar el número de la primera tarjeta con el de la segunda.
    Si el primero es mayor que el segundo, intercambiar las tarjetas. Si no, dejarlas como están.
    Comparar la segunda tarjeta con la tercera.
    Si el segundo número es mayor que el tercero, intercambiarlos.
    Volver a comparar la primera tarjeta con la segunda.
    Si la primera tiene un número mayor, intercambiarlas nuevamente.
    Verificar que los números estén organizados de menor a mayor.
    Mostrar el resultado final.

Fin del algoritmo.

Prueba 1

Números iniciales: 7, 2, 5.

    Primera comparación: 7 es mayor que 2, entonces se intercambian. Resultado: 2, 7, 5.
    Segunda comparación: 7 es mayor que 5, entonces se intercambian. Resultado: 2, 5, 7.
    Tercera comparación: 2 es menor que 5, por lo tanto no se realiza ningún cambio.

Resultado final: 2, 5, 7. 

Prueba 2

Números iniciales: 2, 2, 9.

    Primera comparación: 2 es igual a 2, no se intercambian.
    Segunda comparación: 2 es menor que 9, no se intercambian.
    Tercera comparación: 2 es igual a 2, no se realiza ningún cambio.

Resultado final: 2, 2, 9.

Conclusión

Este ejercicio nos permitió comprender cómo funciona un algoritmo mediante instrucciones claras y ordenadas. Aprendimos que una persona o un computador puede resolver un problema siguiendo reglas específicas, sin necesidad de aprender de ejemplos.

También identificamos el uso de condiciones como "si un número es mayor que otro, intercambiarlos". Estas decisiones permiten que el mismo algoritmo funcione con diferentes números, incluso cuando algunos son iguales.
